🔗 **Canlı sayt:** https://avazazizov.github.io/hands-on-ml-lab/

## Hər mövzuda

1. **Həyatdan misal** — anlayışın gündəlik həyatdakı qarşılığı
2. **Simulyasiya** — slayder və düymələrlə tərpədilən canlı qrafik
3. **Addım-addım bələdçi** — simulyasiyanı özü idarə edir və hər addımı izah edir
4. **Yadda saxla** — əsas qaydalar
5. **Kodda** — Scikit-Learn / PyTorch nümunəsi
6. **Özünü yoxla** — cavabı açılan suallar
